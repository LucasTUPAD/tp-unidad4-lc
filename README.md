Lucas Claveri

Datos Históricos de Temperatura Global - Reporte Mensual

Dataset con Información anual y mensual, desde 1850 a 2026 sobre temperaturas.

El script, evalúa los datos del dataset importándolo desde /datos, para crear un grafico, dando la información sobre cual fue el año mas cálido y frio, desde el 1850 a 2026 y exportando la imagen del grafico, a /resultados.
